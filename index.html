ขั้นตอนการดำเนินการ (Step-by-Step) ของการโอนรถ

การโอนกรรมสิทธิ์รถยนต์และจักรยานยนต์ ต้องดำเนินการตาม 5 ลำดับขั้นตอน ดังนี้:

1. ยื่นเอกสาร

ยื่นคำขอโอน-รับโอน พร้อมสมุดคู่มือจดทะเบียน และหลักฐานบัตร ปชช.

2. นำรถมาตรวจสภาพ

นำรถเข้าช่องตรวจสภาพเพื่อขูดตรวจเลขตัวถังและเลขเครื่องยนต์

3. ประเมินราคา

เจ้าหน้าที่ประเมินราคารถเพื่อคำนวณอัตราอากรแสตมป์ (ร้อยละ 0.5)

4. ชำระเงิน

ชำระค่าคำขอ ค่าธรรมเนียมการโอน ค่าตรวจ และค่าอากรแสตมป์

5. รับเล่มทะเบียน

รับสมุดคู่มือจดทะเบียนที่บันทึกชื่อผู้ถือกรรมสิทธิ์ใหม่เรียบร้อย

จองคิว DLT Smart Queue

  1. โหลดแอป DLT Smart Queue หรือเข้าเว็บ gecc.dlt.go.th
  2. ลงทะเบียนด้วยเลขบัตรประชาชน 13 หลัก
  3. เลือกสำนักงานขนส่งที่ต้องการรับบริการ
  4. เลือกวัน-เวลา และบันทึกภาพหน้าจอคิว

อบรมออนไลน์ e-Learning

  1. เข้าเว็บ www.dlt-elearning.com
  2. กรอกเลขบัตรประชาชน และวันเกิด
  3. ดูวิดีโอจนจบพร้อมตอบคำถาม (1 ชั่วโมง)
  4. แคปผลสอบผ่านไว้แสดงต่อเจ้าหน้าที่ (อายุ 90 วัน)

เกณฑ์ตรวจสภาพ ตรอ.

  • รถยนต์ส่วนบุคคล: เมื่ออายุครบ 7 ปีขึ้นไป
  • รถจักรยานยนต์: เมื่ออายุครบ 5 ปีขึ้นไป
  • ตรวจล่วงหน้าได้ 3 เดือนก่อนภาษีหมดอายุ
  • ค่าตรวจ: รถเก๋ง 200 บาท / มอเตอร์ไซค์ 60 บาท
